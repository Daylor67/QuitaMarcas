## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| gui/stylesheet.py → QApplication | El QSS global se aplica a toda la aplicación — una regla mal especificada puede afectar widgets fuera del scope de WatermarkRemove |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06 | Tampering | WM_STYLE_SHEET scope | mitigate | Todas las reglas usan selectores con ID de objeto (`#wm-*`) — nunca selectores de tipo genérico (`QPushButton { }`) que afectarían toda la app. El prefijo `wm-` es namespace que evita colisiones con otros widgets de SmartStitch |
| T-04-07 | Elevation of Privilege | load_styling() concatenation | accept | La concatenación de strings QSS es trivial y no introduce superficie de ataque; el QSS de qdarktheme es el primero (mayor especificidad base), WM_STYLE_SHEET sobrescribe solo los selectores específicos |
| T-04-08 | Tampering | zoom_overlay_label / manual_overlay_label inline styles | accept | Los dos setStyleSheet() inline que permanecen usan RGBA con transparencia (`rgba(0,0,0,180)`) — este tipo de valor no es expresable directamente en QSS global con la misma semántica de overlay flotante; su permanencia es intencional y documentada (D-13 excepción) |
| T-04-SC | Tampering | npm/pip/cargo installs | accept | No se instalan paquetes en Plan 04-03 |
